♻️ Smart Dustbin Monitoring System
IoT-Based Smart Waste Management and Garbage Collection Navigation

A smart waste management project that monitors garbage levels using Arduino Uno R3, SIM900A GSM module, and ultrasonic sensors. The system displays dustbin information through a Python Streamlit web application with satellite maps and distance calculation.

🌟 Features
🗑️ Smart dustbin garbage-level monitoring.
📩 SMS notification display.
🔄 Message Update button.
📊 Garbage-level dashboard.
🛰️ Satellite map visualization.
📍 Dustbin GPS location tracking.
🚛 Distance calculation from garbage truck to dustbin.
🧭 Google Maps navigation.
🌿 Green-themed user interface.
🛠️ Hardware Components
Arduino Uno R3 Clone
SIM900A GSM Module
HC-SR04 Ultrasonic Sensor
GSM Antenna
